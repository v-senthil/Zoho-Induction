# Zoho Induction

Small C exercises written during Zoho's induction/training program.

## Contents
- `Babylonian.c` — Babylonian (Heron's) method for square roots
- `Happy-Pongal-h.c`, `Happy-Pongal-v.c` — ASCII-art greeting patterns
- `Minesweeper.c` — console Minesweeper
- `Number-Puzzle.c` — a number/sliding-puzzle exercise
- `SiameseMethod.c` — Siamese method magic-square generator
- `SieveOfEratosthenes.c` — prime sieve
- `string-num.c` — string/number manipulation exercise

## Use
Each file is a standalone C program: `gcc <file>.c -o out && ./out`.
